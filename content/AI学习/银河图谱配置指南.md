# 🌌 Obsidian 银河图谱配置指南

> 让你的 Obsidian 知识库长出整片银河！

## 已安装的插件

### 1️⃣ Galaxy View（星系视图）⭐ 推荐首选
**3D 银河星系图谱** — 像 NASA 一样飞行穿越你的知识库！

- **打开方式：** 点击左侧 ribbon 的 🪐 轨道图标
- **或：** `Ctrl+P` → 运行 "Open galaxy view"
- **特色：** 8 套预设风格（银河、旋臂、星云、深空场等）、自动巡游、连接两篇笔记导航

**控制面板说明：**
| 功能 | 说明 |
|------|------|
| 预设选择 | 左上角面板选择 "银河/旋臂/星云" 等风格 |
| 自动旋转 | 默认自动环绕旋转 |
| 漫游模式 | 自动在你重要笔记间穿行 |
| 连接两篇 | 选两篇笔记沿最短路径飞行 |
| 聚焦模式 | 点击节点，只高亮它和邻居 |
| 搜索 | 模糊搜索飞到任意笔记 |

### 2️⃣ Orrery（轨道仪）
**旋转的 3D 银河图谱** — 每篇笔记都是一颗发光的星星

- **打开方式：** 点击左侧 ribbon 的 🌌 轨道图标
- **或：** `Ctrl+P` → 运行 "Open orrery"
- **特色：** 星云背景 + 星空 + 辉光效果

### 3️⃣ Graph Background（图谱背景）
**为 2D 图谱添加自定义背景**

- **设置路径：** `设置 → Graph Background`
- **可设置：** 纯色、渐变、图片背景
- **推荐：** 找一张星空/银河图片设为背景

## 内置 2D 图谱银河美化

我添加了一个 **CSS 代码片段** `galaxy-graph.css`，让你的普通 2D 图谱也有星系效果：

- 🌌 深空渐变背景
- ⭐ 节点变成闪烁的星星
- 🌠 连接线变成柔和星轨

**启用方法：** 
1. 打开 Obsidian → `设置 → 外观`
2. 下滑到 **CSS 代码片段**
3. 点击文件夹图标旁边的 **刷新** 按钮
4. 找到 `galaxy-graph` 并开启开关

## 快速上手

### 方法 A：一键银河效果（推荐）
1. 打开 Obsidian
2. 点击左侧 ribbon 的 🪐 图标 → **Galaxy View**
3. 左上角面板选择「银河」预设
4. 拖动、缩放、点击任意节点 → ✨ 飞向那颗星

### 方法 B：同时启用常规图谱美化
1. `设置 → 外观 → CSS 代码片段` 开启 `galaxy-graph`
2. 打开 `Ctrl+G` 图谱视图 → 已是星空风格

### 方法 C：Orrery（另一种银河）
1. 点击左侧 ribbon 的 🌌 图标
2. 享受自动旋转的 3D 星图

## 更多调优建议

- **节点颜色：** 在 Graph View 设置中自定义颜色分组
- **力导向参数：** 调大斥力让星星更分散，更像真实星系
- **搭配深色主题：** 建议配合深色主题使用（已设为自适应）
- **Galaxy View 快捷键：** `WASD` 自由飞行、`F` 聚焦、`R` 重置视角、`ESC` 退出
