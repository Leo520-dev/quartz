# 离网、并网、混合逆变器对比

## 对比总表

### 核心定位
- **并网 (Grid-Tie)**：光伏并网发电，最大化发电收益
- **离网 (Off-Grid)**：无电网场景独立供电，保障基础用电
- **混合 (Hybrid)**：并网收益 + 储能后备 + 峰谷套利一体化

### 电网依赖度
- **并网**：高度依赖，电网故障必须停机（防孤岛强制要求）
- **离网**：完全不依赖电网，可独立组网运行
- **混合**：双模式兼容，有电并网、无电自动切离网

### 储能电池适配
- **并网**：原生不支持，无电池接口，无法直接接蓄电池
- **离网**：必须搭配蓄电池，是系统核心能量载体
- **混合**：内置双向充放电管理，支持锂电池 / 铅酸电池接入

### 核心工作模式
- **并网**：仅并网发电（自发自用 + 余电上网）
- **离网**：离网逆变供电 + 多源充电（光伏 / 柴发 / 市电）
- **混合**：并网发电、峰谷套利、后备供电、离网独立运行

### 防孤岛保护
- **并网**：强制标配，电网断电毫秒级停机，保障电网检修安全
- **离网**：无此功能（本身为独立供电系统）
- **混合**：并网模式强制开启，离网模式自动解除

### 并离网切换
- **并网**：无切换能力，断网即停机
- **离网**：无切换概念，始终离网运行
- **混合**：支持自动切换，普通机型 10~20ms，高端机型支持 0ms 无缝切换

### 逆变效率
- **并网**：最高，欧洲效率 **97.5%~99%**，仅单向 DC-AC 变换
- **离网**：中等，逆变效率 **93%~96%**，叠加充电损耗后整体效率更低
- **混合**：并网模式接近并网机（**97%~98.5%**），离网模式与离网机相当

### 过载能力
- **并网**：弱，通常仅支持 1.1 倍额定功率持续运行
- **离网**：强，工频机型支持 **2~3 倍过载 5~10 秒**，适配电机、水泵等感性负载启动
- **混合**：离网模式支持 1.5~2 倍过载，并网模式与并网逆变器一致

### 系统核心组成
- **并网**：光伏组件 + 并网逆变器 + 电网 + 负载
- **离网**：光伏组件 + 离网逆控一体机 + 蓄电池 + 负载（可选柴发 / 风电补充）
- **混合**：光伏组件 + 混合逆变器 + 蓄电池 + 电网 + 负载（可选柴发）

### 供电稳定性
- **并网**：完全取决于电网，电网停电即全部断电
- **离网**：取决于储能容量与发电匹配度，与电网无关
- **混合**：**稳定性最高**：并网时电网支撑，停电时电池后备，关键负载可不间断供电

### 同功率初始成本
- **并网**：最低（仅单向逆变功能）
- **离网**：中等（集成 MPPT 充电、AC-DC 整流充电）
- **混合**：最高（集成并网、双向储能、离网稳压三套逻辑）

### 运维复杂度
- **并网**：低，结构简单，无电池维护需求
- **离网**：中高，需定期检测、维护蓄电池
- **混合**：中等，需维护电池，系统控制逻辑更复杂

### 投资回报属性
- **并网**：靠补贴、余电上网回收成本，回报周期明确
- **离网**：无并网收益，仅替代市电 / 柴发成本，回报周期长
- **混合**：靠自发自用提升、峰谷套利、减少停电损失，回报周期介于两者之间

## 加纳市场适配建议

- **电网不稳定区域**（频繁停电）：混合逆变器优先，兼顾并网收益与离网后备。
- **纯离网项目**（偏远无电网）：离网逆变器 + 蓄电池 + 柴发补充。
- **电网稳定区域**（城市核心区）：并网逆变器成本最低，回报最快。
