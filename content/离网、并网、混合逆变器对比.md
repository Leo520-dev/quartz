# 离网、并网、混合逆变器对比

## 对比总表

| 维度 | 并网逆变器 (Grid-Tie) | 离网逆变器 (Off-Grid) | 混合逆变器 (Hybrid) |
|---|---|---|---|
| **核心定位** | 光伏并网发电，最大化发电收益 | 无电网场景独立供电，保障基础用电 | 并网收益 + 储能后备 + 峰谷套利一体化 |
| **电网依赖度** | 高度依赖，电网故障必须停机（防孤岛强制要求） | 完全不依赖电网，可独立组网运行 | 双模式兼容，有电并网、无电自动切离网 |
| **储能电池适配** | 原生不支持，无电池接口 | 必须搭配蓄电池，是系统核心能量载体 | 内置双向充放电管理，支持锂电池/铅酸电池接入 |
| **核心工作模式** | 仅并网发电（自发自用 + 余电上网） | 离网逆变供电 + 多源充电（光伏/柴发/市电） | 并网发电、峰谷套利、后备供电、离网独立运行 |
| **防孤岛保护** | 强制标配，电网断电毫秒级停机 | 无此功能（本身为独立供电系统） | 并网模式强制开启，离网模式自动解除 |
| **并离网切换** | 无切换能力，断网即停机 | 无切换概念，始终离网运行 | 支持自动切换，普通机型 10~20ms，高端机型 0ms 无缝切换 |
| **逆变效率** | 最高，欧洲效率 97.5%~99% | 中等 93%~96%，叠加充电损耗后整体更低 | 并网模式 97%~98.5%，离网模式与离网机相当 |
| **过载能力** | 弱，通常仅 1.1 倍额定功率 | 强，工频机型支持 2~3 倍过载 5~10 秒 | 离网模式 1.5~2 倍，并网模式与并网机一致 |
| **系统核心组成** | 光伏组件 + 并网逆变器 + 电网 + 负载 | 光伏组件 + 离网逆控一体机 + 蓄电池 + 负载（可选柴发/风电） | 光伏组件 + 混合逆变器 + 蓄电池 + 电网 + 负载（可选柴发） |
| **供电稳定性** | 完全取决于电网，停电即全部断电 | 取决于储能容量与发电匹配度，与电网无关 | 最高：并网时电网支撑，停电时电池后备，关键负载可不间断供电 |
| **同功率初始成本** | 最低（仅单向逆变功能） | 中等（集成 MPPT 充电、AC-DC 整流充电） | 最高（集成并网、双向储能、离网稳压三套逻辑） |
| **运维复杂度** | 低，结构简单，无电池维护需求 | 中高，需定期检测、维护蓄电池 | 中等，需维护电池，系统控制逻辑更复杂 |
| **投资回报属性** | 靠补贴、余电上网回收成本，回报周期明确 | 无并网收益，仅替代市电/柴发成本，回报周期长 | 靠自发自用提升、峰谷套利、减少停电损失，回报周期介于两者之间 |

## 加纳市场适配建议

- **电网不稳定区域**（频繁停电）：混合逆变器优先，兼顾并网收益与离网后备。
- **纯离网项目**（偏远无电网）：离网逆变器 + 蓄电池 + 柴发补充。
- **电网稳定区域**（城市核心区）：并网逆变器成本最低，回报最快。
