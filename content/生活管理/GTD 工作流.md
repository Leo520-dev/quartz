# ⚙️ GTD 工作流：Obsidian 中的任务管理

> 用 Obsidian Tasks + Dataview + Reminder 实现完整的待办管理闭环

---

## 📋 任务创建（在任何笔记中）

### 基本语法
| 语法 | 含义 | 示例 |
|------|------|------|
| `- [ ] 任务` | 未完成 | - |
| `- [x] 任务` | 已完成 | - |
| `📅 2026-07-11` | 截止日期 | `- [ ] 交报告 📅 2026-07-11` |
| `⏫` / `🔼` / `🔽` | 优先级 | `- [ ] 紧急任务 ⏫` |
| `🛫 2026-07-11` | 开始日期 | `- [ ] 7月11日开始做 🛫 2026-07-11` |
| `⏳ 2026-07-11` | 计划日期 | `- [ ] 到期前提醒 ⏳ 2026-07-11` |

### 完整示例
```
- [x] 完成项目方案 ✅ 2026-07-10
- [ ] 写周报 📅 2026-07-13 ⏫
- [ ] 学习 Transformer 🛫 2026-07-11 🔼
- [ ] 整理读书笔记 ⏳ 2026-07-15
- [ ] 每周复盘 🔁 every week 📅 2026-07-11
```

---

## 🔄 工作流闭环

### 1️⃣ 收集（收件箱）
- 随时用 `Ctrl+N` 新建笔记记录想法
- 或在日记中用 `- [ ]` 快速记录任务
- 创建 `📥 收件箱` 笔记集中收集碎片想法

### 2️⃣ 处理（每日）
- 早上打开 `Ctrl+D` 打开今日日记
- 查看 [[03-待办/待办总览]] 了解全局任务
- 把收件箱中的内容归类到对应笔记

### 3️⃣ 规划（每周）
- 用 `📅 周计划模板` 创建周计划
- 在 [[03-待办/待办总览]] 中查看下周待办
- 清理已完成任务

### 4️⃣ 执行（每日）
- 从仪表盘看今日任务
- 用 Reminder 插件设置提醒（⏰ 到点弹窗通知）
- 完成即打勾 `- [x]`

### 5️⃣ 复盘（每日/每周）
- 晚间在日记中复盘
- 每周用周计划模板回顾

## 📍 查看任务的地方

| 页面 | 用途 | 打开方式 |
|------|------|---------|
| [[首页配置/仪表盘\|🏠 仪表盘]] | 今日任务 + 本周任务 | 首页 |
| [[03-待办/待办总览\|✅ 待办总览]] | 全局任务看板 | 左侧文件浏览器 |

## 💡 最佳实践

1. **在相关笔记中创建任务** — 比如在「Transformer 架构」笔记中写 `- [ ] 看完 Attention Is All You Need 📅 2026-07-20`，比单独记在待办列表更好
2. **利用标签** — 给任务加 `#urgent` `#learning` `#work` 标签，方便过滤
3. **每日只聚焦 3 件事** — 日记模板中的 Top 3 是每日核心
4. **每周 30 分钟复盘** — 用周计划模板回顾全局
