# ✅ 待办总览

> 全局任务管理看板。所有笔记中的 `- [ ]` 都会在这里汇总。

---

## 🚨 过期任务

```dataview
TASK
FROM !"Templates"
WHERE !completed AND due < date(today)
SORT due ASC
```

## 📌 高优先级

```dataview
TASK
FROM !"Templates"
WHERE !completed AND priority = high
SORT due ASC
```

## 📅 今日待办

```dataview
TASK
FROM !"Templates"
WHERE !completed AND (due = date(today) OR scheduled = date(today))
SORT due ASC
```

## 📆 未来7天

```dataview
TASK
FROM !"Templates"
WHERE !completed AND due > date(today) AND due <= date(today) + dur(7 days)
SORT due ASC
```

## 📋 全部未完成

```dataview
TASK
FROM !"Templates"
WHERE !completed
SORT priority DESC, due ASC
```

---

## ✅ 已完成（今天）

```dataview
TASK
FROM !"Templates"
WHERE completed AND completed >= date(today)
SORT completed DESC
```

---

## 📊 任务统计

```dataview
TABLE length(filter(rows, (r) => !r.completed)) AS "未完成", length(filter(rows, (r) => r.completed)) AS "已完成"
FROM ""
WHERE file.tasks.length > 0
FLATTEN file.tasks AS task
GROUP BY "📊 总计" AS 统计
```

> **💡 提示：** 在任意笔记中用 `- [ ] 任务内容` 创建任务，它们会自动汇总到这里。
> 使用 **Obsidian Tasks** 语法添加日期和优先级：
> - `- [ ] 任务 📅 2026-07-11` — 设置截止日期
> - `- [ ] 任务 ⏫` — 高优先级
> - `- [ ] 任务 🔼` — 中优先级
> - `- [ ] 任务 🔽` — 低优先级
> - `- [ ] 任务 🛫 2026-07-11` — 开始日期
> - `- [ ] 任务 ⏳ 2026-07-11` — 计划日期（到期前提醒）
> - `- [ ] 任务 🔁 every week` — 重复任务
