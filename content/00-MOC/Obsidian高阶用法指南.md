### 2.1 Tasks — 项目管理看板

**已安装但未使用。** Tasks 插件可以把任何 `- [ ]` 待办变成可管理项目。

**配置步骤：**

```
设置 → 插件选项 → Tasks
  → 日期格式: YYYY-MM-DD
  → 全局滤器: not done
```

**用法 —— 在会议纪要里创建任务：**

```markdown
- [ ] 给 Kwame 发报价单 📅 2026-07-15 ⏫
- [ ] 确认逆变器型号 🔼 ➕ 2026-07-12
- [ ] 更新产品选型文档 🛫 2026-07-14 📅 2026-07-18
```

符号含义：
```
📅 2026-07-15  → 截止日期
⏫             → 优先级（高）
🔼             → 优先级（中）
➕ 2026-07-12  → 创建日期
🛫 2026-07-14  → 开始日期
✅             → 完成
```

**查询所有未完成的任务：**

在任意笔记里插入：

```tasks
not done
path includes 01-加纳户储项目
sort by priority
group by heading
```

**效果：** 一个任务看板，按优先级排列，分组显示。
