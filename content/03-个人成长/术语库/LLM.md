# LLM — 大语言模型

## 定义

大语言模型是一种基于海量文本数据训练的深度学习模型，能够理解和生成自然语言。本质上是预测"下一个最合理的词是什么"。

## 详细解释

- 通过阅读互联网级别的文本（书籍/网页/论文），学会语言的统计规律
- 参数量通常在数十亿到数千亿级别（如 GPT-4、DeepSeek-V4）
- 不仅会"说话"，还能推理、翻译、写代码、总结
- 你正在用的我（Roy）就是基于大语言模型运行的

## 类比理解

LLM 就像是一个**读了全世界所有书的实习生**：
- 它没真正"理解"书的内容，但它见过几乎所有的文字组合模式
- 你问它问题，它用见过的模式拼出最合理的回答
- 不是说"知道答案"，而是"知道什么回答最像正确答案"

## 关联概念

- **RAG** (检索增强生成) → 给 LLM 配一本外挂手册，让它能查实时资料
- **Transformer** → LLM 背后的核心技术架构（注意力机制）
- **Token** → LLM 处理文本的最小单位（≈0.75 个英文词 / ≈1.5 个中文字）

## 实际应用场景

- 日常使用的 AI 助手（Roy / ChatGPT / Claude）
- 户储方案自动生成（我正在做的事情）
- 从零学建站的代码辅助
