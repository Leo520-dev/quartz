# 📚 术语库 · 总看板

> 一条术语 = 一条笔记。快速浏览、按领域筛选、一键跳转。

---

## 📊 统计概览

```dataview
TABLE WITHOUT ID
  length(rows) AS "📝 总术语",
  length(filter(rows, (r) => r.掌握程度 = "初识")) AS "🔵 初识",
  length(filter(rows, (r) => r.掌握程度 = "了解")) AS "🟡 了解",
  length(filter(rows, (r) => r.掌握程度 = "掌握")) AS "🟢 掌握",
  length(filter(rows, (r) => r.掌握程度 = "熟练")) AS "⭐ 熟练"
FROM "03-个人成长/术语库"
WHERE 分类
```

---

## 🔍 全部术语速查表

```dataview
TABLE
  分类 AS "📂 领域",
  英文全称 AS "🌐 英文",
  中文释义 AS "📖 中文",
  掌握程度 AS "📊 掌握"
FROM "03-个人成长/术语库"
WHERE 术语名称
SORT 分类 ASC, 术语名称 ASC
```

## ⚡ 快捷操作

| 操作 | 方法 |
|------|------|
| **搜索指定术语** | `Ctrl+Shift+F` → 输入 `path:"术语库" 关键词` |
| **按标签过滤** | 右侧标签面板点击 `#术语` |
| **新增术语** | 复制 `06-模板/术语笔记模板.md` 到本目录即可 |
| **从星图进入** | [[00-MOC/知识星图总览\|📊 知识星图总览]] |
