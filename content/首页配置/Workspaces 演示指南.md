# 🔄 Obsidian Workspaces 工作区演示

你的 Obsidian 已经**启用**了 Workspaces 核心插件（左侧工具栏能看到"管理工作区"图标）。

## 什么是 Workspace？

Workspace 就像浏览器的"标签页会话"——它记住了：
- 你打开了哪些笔记
- 左侧/右侧面板的布局
- 哪些面板是折叠/展开的
- 当前选中的标签

## 实际操作步骤

### 第一步：创建 "AI学习" 工作区

1. 在左侧**文件浏览器**中，点开 `AI学习/` 文件夹
2. 打开 `Transformer 架构.md`、`AI 与机器学习.md`、`RAG 检索增强生成.md`
3. 右侧打开**关系图谱**视图（Graph View）
4. 点击左侧工具栏的**"管理工作区"**图标（🔄）
5. 点 **"管理工作区布局"** → **"保存"** → 输入 `AI 学习模式`

### 第二步：创建 "编程" 工作区

1. 关闭刚才打开的笔记
2. 打开 `Python 基础.md`、`JavaScript 笔记.md`
3. 右侧切换为**大纲**视图
4. **"管理工作区"** → **"保存"** → 输入 `编程模式`

### 第三步：切换自如

- 点击 🔄 → 选择 `AI学习模式` → 一键切换到 AI 学习状态
- 再点击 → 选择 `编程模式` → 一键切换到编程状态

## 小技巧

- 💡 每个工作区可以有不同的**左侧面板折叠状态**（比如"AI学习"展开AI文件夹，折叠其他的）
- 💡 甚至可以不同的**主题配色**（通过 CSS 片段配合）
- 💡 完美配合你的**日报接收**：新建一个工作区专门看日报
