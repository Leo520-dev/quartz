# 🏠 个人知识库仪表盘

> **一次大脑的复制，一个第二大脑。**

---

## ⏰ 今天的任务

```dataview
TASK
FROM !"Templates"
WHERE !completed AND (due = date(today) OR scheduled = date(today))
SORT due ASC
```

## 📅 本周待办（未完成）

```dataview
TASK
FROM !"Templates"
WHERE !completed AND due >= date(today) AND due < date(today) + dur(7 days)
SORT due ASC
```

## 🗂️ 知识领域速览

```dataview
TABLE rows.file.link AS "笔记", length(rows.file.outlinks) AS "出链数"
FROM "AI学习" OR "编程开发" OR "设计创意" OR "生活管理" OR "写作与输出"
SORT length(rows.file.outlinks) DESC
GROUP BY file.folder AS "领域"
```

## 📈 库统计

```dataview
TABLE length(rows) AS "笔记数"
FROM ""
WHERE file.name != "" AND file.folder != "Templates" AND file.folder != ".obsidian"
GROUP BY "📊 总计" AS "统计"
```

> 🗂️ 共 `=length(filter(notes, (n) => !contains(n.file.folder, ".obsidian") AND !contains(n.file.folder, "Templates")))` 篇笔记
> 📎 共 `=length(filter(notes, (n) => contains(n.file.folder, "Templates")))` 个模板

## 🆕 最近修改

```dataview
TABLE file.mtime AS "修改时间", file.etags AS "标签"
FROM ""
WHERE file.name != "" AND file.folder != "Templates" AND file.folder != ".obsidian"
SORT file.mtime DESC
LIMIT 10
```

---

## 🔗 孤立笔记（需要建立链接）

```dataview
TABLE file.folder AS "位置"
FROM ""
WHERE file.name != "" AND file.folder != "Templates" AND file.folder != ".obsidian"
  AND length(file.outlinks) = 0 AND length(file.inlinks) = 0
SORT file.folder ASC
```

---

## 🏷️ 标签云

```dataview
TABLE rows.file.link AS "笔记"
FROM ""
WHERE file.tags != null
FLATTEN file.tags AS tag
GROUP BY tag
SORT length(rows) DESC
```
